# Contributing to VaultProof Agent Guard

Thank you for your interest in contributing to Remnant Fieldworks open-source work.

## How to Contribute

### Reproducing an Experiment (Most Valuable)
The highest-value contribution is independent reproduction. If you can run an experiment from a clean environment and report your results — confirming, challenging, or correcting the findings — that is exactly what open science needs.

To reproduce:
1. Fork this repository
2. Follow the setup instructions in README.md
3. Run the experiment harness
4. Open an issue or PR with your results, environment details, and any discrepancies found

We publish negative results. Corrections are welcome.

### Reporting Issues
- Open a GitHub Issue describing the problem
- Include environment details, steps to reproduce, and expected vs. actual behavior
- For security concerns, email derek@ownerremnantfieldworks.com directly

### Submitting Corrections
- Open a PR with a clear description of what is being corrected and why
- Reference the specific experiment, case record, or claim being updated
- Corrections to the public record are welcomed and attributed

### Code Contributions (vaultproof-agent-guard)
- Open an Issue first to discuss the proposed change
- Submit a PR with clear description
- All PRs require passing CI checks

## Standards
- Claims must be grounded in reproducible evidence
- Methodology changes require a new preregistration or amendment to the existing one
- Negative results and failures must be preserved, not deleted
